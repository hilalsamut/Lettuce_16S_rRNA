# Figures Folder
This folder contains visual outputs from each step of the microbial community analysis. Figures are organized into subfolders that mirror the structure of the analysis pipeline.
## Folder Structure:
- `01_QualityTrimming/`: Plots showing read quality before and after filtering
- `02_AssignASVs/`: Visualizations of ASV counts, length distributions, chimera detection.
- `03_PreProcessing/`: Plots related to sequencing depth
- `04_PhylogeneticTree/`: Tree visualizations, rooted/unrooted trees
- `05_Biodiversity/`: Alpha diversity boxplots
- `06_Ordination`: Ordination plots showing sample clustering based on distance matrices.
- `07_Composition/`: Taxonomic composition across groups
